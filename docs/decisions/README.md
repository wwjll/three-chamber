# Decisions

Design decisions that shape more than one change. Each record says what was
decided, why, and what was rejected, so later work does not reopen settled
questions by accident. Name files `YYYY-MM-DD-topic.md` using the date of the
decision. When a decision is replaced, add a new record and link it from the
old one instead of rewriting history.
