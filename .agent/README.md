# Agent Configuration

This directory stores project-level conventions and working agreements for
automated coding agents.

## Specifications

- [Coding standards](./coding-standards.md)
- [Demo media standards](./demo-media-standards.md)
- [Path tracer roadmap](./path-tracer-roadmap.md)
- [Validation](./validation.md)

Add one [change log entry](../docs/changes/README.md) for each batch that lands on `main`.
Before pushing a batch that changes examples, ask whether their screenshots or
GIFs need updating, as described in
[Updating Media Before a Push](./demo-media-standards.md#updating-media-before-a-push).

Add new conventions here when they are agreed upon so future changes can follow
the same rules consistently.
